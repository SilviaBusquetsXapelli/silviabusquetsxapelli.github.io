What is GDP?

GDP measures the value of final goods and services produced in an economy over a period.

The basic idea

GDP is a way to summarise economic production. It is useful for comparing the size of an economy and tracking whether production is growing or shrinking.

What GDP does not tell you

GDP is not the same as household wellbeing. It does not by itself tell you how income is distributed, how much unpaid work occurs, or whether growth is environmentally sustainable.

Nominal vs real

Nominal GDP uses current prices. Real GDP adjusts for price changes so that economists can better separate changes in production from inflation.
