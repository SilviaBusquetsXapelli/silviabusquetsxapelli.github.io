# Silvia Busquets Xapellí — Economics, Finance & European Affairs

An interactive learning project focused on **economics, finance and European institutions**.

The website is designed around a simple idea: learning by explaining. Each topic combines clear explanations with interactive exercises, scenarios, visual tools and interview-style practice.

## 🌐 Live website

**[Visit silviabusquetsxapelli.github.io](https://silviabusquetsxapelli.github.io/)**

## About the project

This website serves both as a learning platform and as a professional portfolio.

Its purpose is to:

- build a structured understanding of economics, finance and European affairs;
- turn complex concepts into clear, accessible explanations;
- practise applying knowledge through interactive activities and scenarios;
- support preparation for interviews, EU careers and competitive selection processes;
- demonstrate the ability to analyse, structure and communicate technical subjects clearly.

## Learn

The **Learn** section is the core of the website.

Topics are organised into learning paths rather than isolated files or PDFs. Each lesson can include:

- concise explanations and key concepts;
- interactive sliders and calculators;
- matching and ordering exercises;
- scenario-based questions;
- quizzes and knowledge checks;
- interview-style questions and answer frameworks;
- key takeaways and official sources;
- browser-based progress tracking;
- a clean **Print / Save as PDF** version generated directly from the page.

Current learning areas include:

### European Union
- EU institutions
- How EU law is made
- EU budget

### Economics & Monetary Policy
- Inflation
- ECB monetary policy and transmission

### Finance
- Bonds and yields

The library is designed to grow progressively as new topics are researched and studied.

## Learning paths

The content can also be followed through structured routes such as:

- **Understand the EU**
- **ECB & Monetary Policy**
- **Finance Foundations**
- **EU Careers / AD5 preparation**

The same lesson can belong to more than one learning path, keeping the site organised without duplicating content.

## Books

The website may also feature selected **paid books available through Amazon** when they are directly related to economics, Europe, institutions or learning.

Books are complementary to the free learning material rather than copies of it. References from lessons are intentionally subtle and only appear when a book is genuinely relevant to the topic.

## Technology

The site is intentionally lightweight and runs entirely on GitHub Pages using:

- HTML
- CSS
- vanilla JavaScript
- `localStorage` for browser-only study progress

No account, database or server is required for the interactive learning features.
