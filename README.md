## About

This website brings together clear explanations interactive exercises and structured learning paths across economics finance and European institutions.

The Learn section includes topic based lessons practical scenarios quizzes and browser based progress tracking. Selected books connected to the same subject areas are presented separately in the Books section.

## Main sections

- **Learn** for interactive lessons and learning paths
- **Books** for selected publications related to Europe economics and institutions
- **About** for background and professional links

## Technology

The site is built with HTML CSS and vanilla JavaScript and is hosted with GitHub Pages.
