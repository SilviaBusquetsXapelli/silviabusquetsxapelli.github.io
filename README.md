## About

This website brings together clear explanations interactive exercises and structured learning paths across economics finance and European institutions.

The Learn section includes topic based lessons practical scenarios quizzes and browser based progress tracking. Selected books connected to the same subject areas are presented separately in the Books section.

## Main sections

- **Learn** for interactive lessons and learning paths
- **Books** for selected publications related to Europe economics and institutions
- **About** for background and professional links

## Technology

The site is built with HTML CSS and vanilla JavaScript and is hosted with GitHub Pages.

## v30 map behaviour
- Category filters affect only the country/flag cards below the map.
- Filtering clears any selected country.
- The map remains neutral regardless of category.
- Selecting a country (from the map or flags) highlights only that country and zooms to it.
- Microstates and very small islands use a stronger zoom tier; map max zoom increased to 16.


## v50 Kids visual facts
- Curated visual facts only: photos are shown only when they directly illustrate a fact.
- Maximum 2 photos per country; no generic fallback photo searches.
- Larger two-column cards on desktop and one-column cards on mobile.
- Guess the Country reuses only the curated visual clues when available.
